# LinkNote 软件说明书

LinkNote 是一款用于课程学习和论文阅读的本地桌面笔记软件。本说明供组内讨论软件功能、开发分工和交接方式。

## 软件功能

用户可以新建、编辑、预览和保存笔记，用关键词查找以前写过的内容。一篇笔记可以链接到另一篇笔记，被链接的笔记也能看到有哪些笔记引用了它。图谱用节点表示笔记，用连线表示这些引用关系。

软件有两类笔记。普通笔记用于记录课程内容、代码和公式。Paper 笔记用于整理论文的基本信息、研究问题、方法、贡献和局限。两类笔记都以 Markdown 文件保存在电脑上，编辑、搜索和图谱可以离线使用。AI 处理用户选定的材料，需要联网和用户提供的密钥。

## 三人分工

### A 笔记软件

负责主窗口、文件夹和笔记列表、编辑与预览、关键词搜索和文件保存。用户可以新建文件夹，新建、打开、删除和重命名单篇笔记。删除前提示确认并保留可恢复副本。保存失败时保留编辑内容，发现文件已被其他程序修改时停止覆盖。

A 为其他模块提供统一的笔记读取和保存方式，并将 B 的反链与图谱界面、C 的 Paper 与 AI 界面接入主窗口。

### B 知识关联与图谱

负责识别笔记中的链接，支持点击跳转和查询反链。两篇笔记同名时，用文件路径指定目标。反链和图谱都根据已保存的笔记生成，失效链接在笔记中提示，图谱只展示有效关系。

B 负责图谱的自动布局、拖动和缩放，用户可以点开图中的笔记。重命名笔记时，B 查找受影响的引用并生成修改清单，A 负责检查、备份和写入。写入完成后，B 更新反链和图谱。

### C AI 与文献管理

负责 Paper 表单、AI 设置和结果审核。用户可以填写论文信息，也可以粘贴摘要或正文，由 AI 提取研究问题、方法、贡献和局限。材料未说明的字段标为未知，提取结果先显示给用户审核。

C 负责外部服务调用、超时和错误提示，并提供离线模拟供联调。软件只发送用户选定的材料。需要写入笔记的 AI 建议须经用户确认，再通过 A 的保存入口提交。如果原文已经修改，旧建议不能直接覆盖新内容。密钥由用户提供，不能写进项目文件或提交到仓库。

## 先做哪些功能

**本期必做**的是普通笔记的文件管理、编辑预览和手动保存，关键词搜索、双链与反链、笔记重命名和基础图谱，以及 Paper 表单、当前材料总结和论文信息提取。基础功能通过后，确认软件可以通过 Windows 发布包启动。

**有余量再做**的是 AI 关联推荐、写作整理和阅读增强。优先实现由用户手动选几篇笔记、AI 给出关联建议、用户确认后再建立链接。随后评估写作整理、润色、提纲、翻译、解释和针对当前材料提问。自动保存、多标签页和图谱路径查询也按剩余时间安排。

## 如何交接和联调

- **论文提取**：C 展示提取结果，用户确认后由 A 保存 Paper。若采纳的是新增链接，等保存成功后由 B 更新反链与图谱。
- **仓库与发布**：C 负责前期建立 GitHub 仓库、统一构建方式和组织联调。B 接手后期的模块合并、打包和发布。
- **日常协作**：一项任务对应一个分支，合并前由另一位组员审查。涉及共用接口时请使用方审查。每周两次用同一份样例笔记和同一个版本联调。

详细的数据规则、测试和交付要求见 [LinkNote V1.2 项目开发计划书](linknote_v1_2_development_plan.md)。
